# 瑞土酵生原生微信小程序

本目录可直接导入微信开发者工具。项目只使用原生 WXML、WXSS 和 JavaScript，不依赖 uni-app、Taro、WePY 或 npm 包。

## 页面

- `pages/home/home`：项目总览、核心数据、循环链路、产品概念与场景插画
- `pages/story/story`：痛点、瑞溪村背景、协作主体与项目故事
- `pages/tech/tech`：农用酵素定义、三阶段交互、酸菌协同、原料分类与工坊流程
- `pages/result/result`：应用成果、成本示例、案例图谱与本地验证清单
- `pages/join/join`：参与角色、落地路线、共创意向表单和研学打卡

## 设计说明

小程序不打包团队课件中的原始照片。田间、工坊、产品和村庄场景均由 WXSS 图形与文字组成，风格与网站 SVG 视觉统一，同时避免把概念场景误作本地实拍。

## 导入与发布

1. 微信开发者工具 → 导入项目 → 选择当前目录。
2. 预览可保留 `touristappid`；正式项目请修改 `project.config.json` 中的 `appid`。
3. 当前没有网络请求；共创意向和打卡状态只保存在本机，不会上传。
4. 正式提交前检查小程序名称、服务类目、隐私保护指引、域名白名单、接口备案和内容口径。
5. 主包体积远低于常见 2 MB 限制，仍建议在开发者工具中执行“代码质量”和“上传前检查”。
