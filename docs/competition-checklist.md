- [ ] 瑞溪村示范田对照设计、时间、面积和施用记录
- [ ] 土壤有机质、pH、养分与团粒结构检测报告
- [ ] 番茄等作物农残、品质、产量和测产报告
- [ ] 农户化肥、农药、菌剂、人工和运输成本台账
- [ ] 农户访谈、授权书和村集体/合作社盖章证明
- [ ] 奶茶、冰淇淋配方小试、成本、感官评价和食品安全路径
- [ ] 研学客流、支付意愿、渠道意向和试销反馈
- [ ] 如答辩另行展示原始照片，补齐拍摄地点、时间、人物授权和版权来源

## 路演表达边界

- 把“外地案例数据”说成技术可行性证据，不说成瑞溪村实测结果。
- 把“团队测算”说成假设与目标，不说成已实现收益。
- 把奶茶、冰淇淋说成增值配套，不让其取代酵素循环生态农业主线。
- 对具体稀释倍数、施用频率和病虫害处方，使用技术人员确认后的正式版本。
- 网站、小程序与商业计划书使用同一项目全称、数据口径和“插画 / 实拍 / 检测图”标注。
