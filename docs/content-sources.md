## 1. 项目定位与产品体系

来源：《国创赛分工(1).doc》

- 项目名称：“瑞土酵生”
- 副标题：“农废酵素循环生态种植 + 农产年轻化深加工乡村振兴方案”
- 双层产品体系：生态种植番茄、玉米、大米；番茄鲜汁奶茶、谷物大豆基底冰淇淋
- 运营设想：村级公益微型工坊、农废置换、联名代销、数字化原料登记和研学预约

## 2. 农用酵素技术原理与案例数据

来源：《兰考县酵素技术培训会.pptx》

- 定义：以废弃瓜果蔬菜等高湿高糖废弃物为培养基，在厌氧条件下获得本地有益微生物
- 本质：生物发酵技术 + 废弃物循环利用模式
- 三阶段：水解、产酸、后熟
- 机理：乳酸、乙酸等酸基物质与有益微生物形成“酸菌协同”
- 分类：果蔬类、动物源、中药材等功能方向
- 跨区域案例汇总：菌剂成本降低 90% 以上、肥料成本降低 60% 以上、作物产量提高 8%–20%、累计培训 1000+ 人次
- 成本示例：成品采购约 400 元/亩次，自制发酵约 133 元/亩次

上述数字均按“培训材料案例数据”显示，不可直接写成瑞溪村实测结论。

## 3. 瑞溪村背景

来源：《瑞溪村简介.docx》

- 2019 年底三甲村与河溪村合并为瑞溪村
- 原底三甲片区位于瑞安市马屿镇，具有丘陵与河谷平原过渡地貌
- 数十年大棚番茄种植传统，并配套甜瓜、茄子、黄瓜等作物
- 瓯窑缸窑窑址、约 1.5 公里的宋窑古道等文化资源
- 酵素工坊、堆肥生产和扫码溯源等校地合作实践

村庄项目进度、收入预估、数字系统运行情况等时间敏感信息，正式展示前应由村方复核。
